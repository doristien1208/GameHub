更萊姆遊戲 入口網站與主控制器 部署說明
======================================

這個資料夾是「更萊姆遊戲」入口網站：同事只要開一個網址，就能看到所有遊戲的狀態並進入遊戲。
主控制器也負責把遊戲開起來、當掉時重開、維護時關掉。不需要 npm install，也不需要 nginx。

  dist\                    主控制器本體與入口網頁
  assets\                  遊戲列表的縮圖（200x200），檔名寫在 hub.config.json 的 "image"
  hub.config.json          實際設定（第一次啟動時自動建立；之後更新版本不會被覆蓋）
  hub.config.example.json  設定範例
  start-hub.bat            啟動主控制器（雙擊，會開一個視窗）
  install-autostart.bat    設成開機自動啟動（系統管理員執行一次）
  remove-autostart.bat     停止主控制器並取消開機自動啟動
  open-firewall.bat        開放防火牆（系統管理員執行一次）
  logs\                    hub.log（主控制器）、<遊戲 id>.log（各遊戲的輸出）、launcher.log


一、需求
--------
- Windows，已安裝 Node.js 22.18.0
- 這個資料夾跟各遊戲的資料夾放在同一層，例如：
    D:\games\GameHub
    D:\games\BnB


二、第一次安裝
--------------
1. 關掉原本手動開著的遊戲視窗（例如水球大亂鬥的 start-server.bat），之後改由主控制器開。
   忘了關也沒關係：入口會顯示「運行中」，管理模式按「接管」就會改由主控制器負責。
   但有些遊戲的 start.bat 會在程式結束幾秒後自己重開（視窗裡會出現 Restarting），
   接管後會被它搶回去：這種視窗請直接在這台電腦上關掉。
   之後各遊戲都不要再用自己的 start.bat 或排程開機啟動，改由主控制器負責，免得搶同一個埠。
2. 在 open-firewall.bat 上按右鍵，選「以系統管理員身分執行」（開放 TCP 4300）。
3. 如果有開著的主控制器視窗（雙擊 start-hub.bat 開的），先關掉；遊戲會繼續跑。
   在 install-autostart.bat 上按右鍵，選「以系統管理員身分執行」。
   它會建立排程工作「Game Hub」：用執行這個檔案的帳號在背景執行（不存密碼、沒有視窗、
   開機後不用登入就會啟動），並等幾秒確認主控制器真的跑起來，才顯示 Done 與
   「Task runs as <帳號>, state Running」。這個帳號要能讀寫 GameHub 與各遊戲的資料夾。
   之後每次開機都會自動啟動。只想先試試看：直接雙擊 start-hub.bat。
4. 瀏覽器開 http://<這台電腦的 IP>:4300 ，看到遊戲列表就完成了。
5. 管理密碼在 hub.config.json 的 adminPassword（第一次啟動時自動產生，可以自己改）。


三、維護與更新遊戲（不用到這台電腦前面，透過共享資料夾就能做）
------------------------------------------------------------------
1. 在該遊戲的資料夾放一個 maintenance.txt，內容寫要顯示的訊息，例如：
     更新到 v0.3，約 10 分鐘
   入口會立刻顯示「維護中」並擋住「進入遊戲」。
   如果遊戲回報還有局在打，會等這局結束才關（最多等 15 分鐘）。
2. 等入口顯示「維護中」（代表遊戲已經關了），再覆蓋新版檔案。
3. 刪掉 maintenance.txt。主控制器會自動把遊戲開回來，入口會顯示新的版本號。
請用 UTF-8 存 maintenance.txt（Windows 記事本預設就是）；其他編碼的中文會顯示成「維護中」。


四、日常
--------
- 入口：http://<IP>:4300 。右下角「管理」輸入密碼後，可以啟動、停止、重啟、接管遊戲，以及看紀錄。
- 遊戲當掉會自動重開（間隔 1、2、4… 秒，最多 60 秒）；超過 60 秒沒有回應也會重開。
- 主控制器重開不會中斷遊戲：遊戲繼續跑，主控制器起來後會自動接回。
- 在管理模式按「停止」的遊戲，主控制器會記住，重開機後也不會自己開；要按「啟動」。


五、加入或修改遊戲
------------------
入口的遊戲列表就是 hub.config.json 裡的 "games"，網頁不用改。新增一個遊戲：
1. 縮圖（200x200 的 png 或 jpg，英數字檔名）放進 assets 資料夾。
2. 在 hub.config.json 的 "games" 加一筆（欄位見下面）。
3. 存檔。約 5 秒後主控制器自動套用，開著的入口頁也會自己多出這個遊戲。
主控制器重開時遊戲不受影響；寫錯的話 logs\hub.log 會說哪裡錯，並繼續用舊設定。
換縮圖：用同樣的檔名覆蓋 assets 裡的圖即可，入口會自動換成新圖。
每個遊戲的欄位：

  "id": "bnb"                        英文、數字、- 或 _，用在網址與紀錄檔名
  "name": "水球大亂鬥"               入口上顯示的名稱
  "image": "bnb.png"                 （選填）列表的縮圖：assets 資料夾裡的檔名；沒有就顯示名稱的第一個字
  "desc": "一句話說明"               （選填）
  "dir": "../BnB"                    遊戲資料夾（相對於這個資料夾）；maintenance.txt 放這裡
  "command": "node"                  啟動指令；"node" 代表這台電腦的 Node.js
  "args": ["dist/server/index.js"]   指令後面的參數
  "port": 3000                       遊戲的埠（主控制器啟動時會設定 PORT 環境變數）
  "health": "/healthz"               （選填）健康檢查網址；回傳 JSON {version, online, playing} 最好
  "autoStart": false                 （選填）主控制器啟動時先不要開這個遊戲

- 沒有 command 的遊戲：主控制器只顯示它連不連得到並放連結，不幫它開關。
- "title"：網站名稱（預設「更萊姆遊戲」），顯示在頁面最上面與瀏覽器分頁。
- "links"：入口下方「其他連結」，每個是 {"name": "...", "url": "...", "desc": "..."}。
- "port"：入口的埠（預設 4300）；改了要再執行一次 open-firewall.bat 新的埠。


六、更新主控制器本身
--------------------
把新版的 dist 資料夾整個覆蓋舊的，再執行 remove-autostart.bat 與 install-autostart.bat
（或在「工作排程器」裡把 Game Hub 結束後再執行）。遊戲不受影響。


七、問題排除
------------
- 入口打不開：先在這台電腦開 http://localhost:4300 。本機可以、別台不行，通常是防火牆，
  請用系統管理員身分執行 open-firewall.bat。
- 看 logs\hub.log 與 logs\launcher.log；遊戲自己的輸出在 logs\<遊戲 id>.log
  （管理模式按「紀錄」也看得到）。
- 遊戲一直顯示「當掉了」：看那個遊戲的紀錄；常見原因是 dir 或 command 寫錯、埠被別的程式占用。
- 入口顯示「運行中」，但管理模式只能按「接管」：那個埠被手動開的視窗占用，按「接管」即可。
- 開機後主控制器沒起來：用系統管理員開命令提示字元，執行
    schtasks /query /tn "Game Hub" /v /fo list
  看「上次結果」：1 通常是執行的帳號進不了資料夾；267011 是還沒執行過。
  執行帳號被停用或刪除時，用另一個能進這些資料夾的管理員帳號重新執行 install-autostart.bat。
- 縮圖沒出來（顯示名稱的第一個字）：檢查 "image" 的檔名跟 assets 裡的檔案是否一致（含大小寫與副檔名）；
  logs\hub.log 會寫哪一張找不到。
